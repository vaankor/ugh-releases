# Ultimate Gaming Hub

Программа для Windows, которая собирает всё игровое в одном месте.

- **Игры и быстрый запуск** — библиотека игр с ваших лаунчеров, запуск в один клик и горячими клавишами.
- **Новости и календарь** — новости по вашим играм и даты выхода новинок.
- **Контент** — свежие видео, Shorts и стримы с YouTube и Twitch по вашим играм.
- **Статистика Steam** — каталог, цены и скидки Steam.
- **Мои устройства** — телефон Android рядом с ПК: буфер обмена, файлы, трансляция экрана, телефон как веб-камера (по USB или Wi-Fi).
- **Инструменты, оптимизация и софт** — полезные утилиты, настройка ПК под игры, установка и обновление программ.
- Русский, английский и украинский языки, тёмная и светлая темы, обновления прямо в программе.

## Скачать

[Releases](../../releases/latest) → `UltimateGamingHub_<версия>_x64-setup.exe` (Windows 10/11, x64).

С версии 1.22.0 программа обновляется сама: только после нажатия «Обновить» и только с верной цифровой подписью.

<summary>Для владельца</summary>

Этот репозиторий — только готовые версии: установщики и файлы обновления, исходники здесь не хранятся. Настройка и выпуск — в `UGH-RELEASE-GUIDE.md` приватного репозитория.

| Путь | Назначение |
|---|---|
| `.github/workflows/publish.yml` | ручной workflow «Publish UGH release»: check / test / publish / withdraw |
| `release-config/updater.pub` | закреплённый открытый ключ обновлений |
| `scripts/ugh_ci_updater.py` | проверка манифеста, подписи и ключа внутри программы |
| `tools/package*.json` | закреплённая версия Tauri CLI для подписи |

Секреты — только в Environments: `release-source` (токен чтения, только `main`) и `release-signing` (ключ подписи, только `main`, с обязательным подтверждением).

</details>
